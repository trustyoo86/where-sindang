# 03 — UI 연결 메모 (search-ui)

## 변경/추가 파일
- 추가 `src/components/PlaceCard.tsx` — page.tsx 인라인 카드를 분리(클라이언트 검색에서 재사용).
- 추가 `src/components/PlaceSearch.tsx` (`"use client"`) — 검색 입력 + 필터 결과 그리드.
- 변경 `src/app/page.tsx` — "오늘의 신당" 그리드를 `<Suspense><PlaceSearch /></Suspense>`로 교체, 인라인 `PlaceCard` 제거, 미사용 import 정리.

## 컴포넌트: PlaceSearch
- props 없음. `searchPlaces(query)`(02 계약)만 호출 — 로직 재구현 안 함.
- 상태: `query`(검색어). 초기값은 URL `?q=`.
- URL 동기화: `router.replace`로 `?q=` 갱신(`scroll:false`). 빈 검색어면 `q` 제거.
- 0건: "검색 결과가 없어요" 안내. 빈 검색어: `searchPlaces`가 전체 반환 → 전체 표시.

## 디자인 준수 (DESIGN.md)
- 검색 pill: 흰 배경 + 20px radius + `--shadow-subtle` 3스택.
- 검색 아이콘 버튼: 40px(h-10 w-10) 원형, #ff385c 배경(브랜드 색은 여기만).
- radius: 14(input)/20(pill)/full(버튼) — 허용값만.
- 카드 그림자 없음(PlaceCard 그대로).

## Suspense 이유
`useSearchParams`는 정적 렌더 시 Suspense 경계를 요구 → page에서 `<Suspense>`로 감쌈.

## 참고
- Hero의 장식용 Where/Mood/When pill은 그대로 둠(히어로 비주얼). 실제 이름 검색은 "오늘의 신당" 섹션의 검색바.
